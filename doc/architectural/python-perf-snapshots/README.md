# Persisted perf-report snapshots — AWS Python benchmark suite

Two snapshot families capture the before/after picture for
the optimisations described in `../python-perf-analysis.md`.

## Naming

Three text files per benchmark, generated by `perf report`:

* `<bench>.report-self.txt` — `--no-children
  --percent-limit 0.5`. Self-time only (cycles spent
  literally executing the function in question, not its
  callees). Useful for spotting tight inner loops.
* `<bench>.report-children.txt` — `--children
  --no-call-graph --percent-limit 0.5`. Self + descendant
  time per symbol, no call-graph context. The headline
  table for "where is the run spending its budget".
* `<bench>.report-callgraph.txt` — `--children
  --percent-limit N -g graph,K,callee`. Trimmed callgraphs
  for the hottest paths. Stricter limits where data was
  voluminous (small benchmarks have few samples; even minor
  symbols pass low thresholds, blowing up file sizes).

## Raw `perf.data` archive

Original `perf.data` files (not committed — too large) live
at:

```
~/python-perf-archive/<bench>.perf.data{,.zst}        # family 1
~/python-perf-archive/final/<bench>.perf.data.zst     # family 2
```

Total compressed: ~70 MB (~38 MB family 1 + ~33 MB family 2).

To regenerate the text reports from a `.perf.data`:

```bash
zstd -d <bench>.perf.data.zst   # if compressed
perf report -i <bench>.perf.data --stdio --percent-limit 0.5 \
    --no-children > <bench>.report-self.txt
perf report -i <bench>.perf.data --stdio --percent-limit 0.5 \
    --children --no-call-graph > <bench>.report-children.txt
perf report -i <bench>.perf.data --stdio --percent-limit 15 \
    --children -g graph,2,callee > <bench>.report-callgraph.txt
```

## Reproducing from scratch

```bash
# Build a debug-info CBMC for source-level profiling
cmake -S . -B build-debug -DCMAKE_BUILD_TYPE=RelWithDebInfo -DWITH_JBMC=OFF
cmake --build build-debug --target cbmc -j$(nproc)

# Lower perf paranoid level (root)
sudo sysctl kernel.perf_event_paranoid=-1

# Start the parse daemon (family 2 only)
export CBMC_PYTHON_SERVER_SOCKET=$(scripts/cbmc_python_server start)

# Profile a specific benchmark
export PYTHONPATH=$HOME/python-verification-benchmarks/stubs-full-python
ulimit -v unlimited
perf record -g --call-graph dwarf,8192 -F 997 -e cycles:u \
    -o /tmp/bench.perf.data \
    -- build-debug/bin/cbmc \
    $HOME/python-verification-benchmarks/python-sources/<bench>.py \
    --object-bits 12 --no-unwinding-assertions --unwind 3 \
    --python-no-exception-checks --python-required-kwarg-checks \
    --python-check-typeddict-fields                    # default
    [--smt2 --cvc5]                                    # cvc5

# Stop the daemon
scripts/cbmc_python_server stop
```
